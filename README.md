# 浪人崛起 内置 DLL 修改器（精简版）

**中文** | [English](README_EN.md)

## 做什么

浪人崛起 内置 dll 修改器，开游戏即激活。本分支只保留 3 项功能。

## 功能

1. 自动石火
2. 无视套装件数需求
3. 物品不减

## 配置

`Ronin_Cheats.ini` 共 3 项，每项都能单独开关：

| 配置项 | 取值 | 说明 |
|---|---|---|
| `enable_auto_parry` | `1` / `0` | 自动石火 |
| `enable_no_set_req` | `1` / `0` | 无视套装件数需求 |
| `enable_inf_item` | `1` / `0` | 物品不减 |

## 使用方法

1. 把 `dinput8.dll` 和 `Ronin_Cheats.ini` 放进游戏根目录
2. 启动游戏，自动生效
3. 改完配置保存，重启游戏生效

卸载：删掉游戏根目录的 `dinput8.dll`。
