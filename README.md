# 浪人崛起 内置修改 DLL

## 做什么

游戏启动时自动加载的内置修改。改内存不改游戏文件，存档不受影响，不需要另开修改器。

支持的功能：

| 功能 | 能否单独开关 |
|---|---|
| 无限物品使用 | ✅ 可以 |
| 增加石火时机 | ❌ 随总开关 |
| 自动石火 | ❌ 随总开关 |
| 所有流派石火有利效果 | ❌ 随总开关 |
| 增减益(buff)控制 | ❌ 随总开关 |
| 角色状态值 | ❌ 随总开关 |
| 气焰 | ❌ 随总开关 |
| 无视套装件数需求 | ❌ 随总开关 |
| 人物动作速度 | ❌ 随总开关 |

## 怎么用

1. 把 `dinput8.dll` 和 `Ronin_Cheats.ini` 放进游戏根目录（和 `Ronin.exe` 同目录）
2. 启动游戏，自动生效
3. 想改功能 → 编辑 `Ronin_Cheats.ini` → 保存 → 重启游戏

**卸载**：删掉游戏根目录的 `dinput8.dll` 即可。

## 怎么配置

`Ronin_Cheats.ini` 只有 4 个配置项：

| 配置项 | 取值 | 作用 |
|---|---|---|
| `enable_inf_item` | `1` / `0` | 无限物品使用。唯一能单独开关的功能。 |
| `enable_hooks` | `1` / `0` | 其余 8 项功能的总开关，只能全开或全关。 |
| `max_hooks` | `0` / `N` | `0` = 安装全部 17 条 hook；`N` = 只装前 N 条，用于二分排查崩溃。 |
| `log_verbose` | `0` / `1` | `1` = 在游戏根目录生成 `Ronin_Cheats.log`，记录每条 hook 的安装结果。 |

### 注意事项

- **`enable_inf_item` 和 `enable_hooks` 删掉整行 = 关闭**（代码默认值为 0）。
- **`max_hooks` 这行不要删**：删掉后程序按默认值 `1` 处理，只会安装 1 条 hook，等于全部功能失效。
- 那 8 项功能共用一个总开关，目前无法单独控制。
- 「手枪无需装填」未实现。

## 编译

```bash
cd dll
python build.py
```

需要 Visual Studio（含 C++ 工具链）+ Windows SDK。
